# WhatsApp PBX - Windows App

WhatsApp PBX is a Windows-based VoIP / SIP softphone client customized for WhatsApp BD PBX integration.

## Features
- SIP / VoIP calling (Audio & Video)
- Contact and Call Log management
- Custom dialer & configurable shortcuts
- Low latency & lightweight footprint

## Building from Source
- Microsoft Visual Studio (C++ Desktop Development with MFC)
- Open `microsip.vcxproj` and build for `Release` or `Debug` (`Win32` / `x64` / `ARM64`).
- Output executable: `WhatsApp PBX.exe`
